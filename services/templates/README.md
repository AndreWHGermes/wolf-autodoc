# services/templates/ — правила по конкретным бланкам

Здесь живут правила, которые применяются **только к определённым шаблонам документов**
(банковские справки, договоры, письма в иммиграцию, резюме, E-02).

Каждый подкаталог — это **один тип документа**. Каждый `.py` файл — это правила для одного
или нескольких связанных шаблонов (например, tbank.py покрывает 3m и 12m Т‑Банка).

## Принцип

- Правило лежит **рядом с тем, что оно регулирует**, а не в общем `values.py`.
- Импорт правил — через `registry.py`: `TEMPLATE_RULES[code] = module`.
- При правке правила для конкретного бланка ты меняешь **один файл**, не перерывая
  весь `services/`.

## Структура

```
services/templates/
├── bank_statements/      — справки об остатке
│   ├── tbank.py          — 3m и 12m Т‑Банка
│   ├── sber.py           — 3m и 12m Сбера
│   └── _common.py        — общая логика справок
├── contracts/            — договоры
│   ├── remote_work.py
│   └── employment.py
├── letters/              — письма в иммиграцию
│   ├── bridging.py       — BRIDGING (3 офиса × общий каркас)
│   └── conversion.py
├── cv/                   — резюме
│   └── sivaev.py         — единственный формат CV
├── e02.py                — Statement Letter
└── registry.py           — TEMPLATE_RULES[code] = module
```

## Кто сюда пишет

- При появлении нового бланка — добавляешь подкаталог/файл и регистрируешь в `registry.py`.
- При правке правила для существующего бланка — открываешь только его файл.

## Кто импортирует

- `services/values/orchestrator.py` — вызывает правила при сборке значений.
- `services/autofill.py` — запрашивает правила рендера и проверок.
