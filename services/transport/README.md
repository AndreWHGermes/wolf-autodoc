# services/transport/ — внешние интеграции

Всё, что связано с обменом данными с внешним миром: Google Drive, OAuth, троттлинг.

## Принцип

- Один сервис = один файл. Никакой бизнес-логики документов.
- Каждый модуль принимает настройки через `core/config.py`, не через глобальные переменные.
- Ошибки транспорта не должны ломать сборку документа — только отправку.
- Все обращения логируются в `core/log.py` с категорией `transport`.

## Структура

```
services/transport/
├── gdrive_read.py        — чтение файлов клиента с GDrive (scope drive.readonly)
├── gdrive_write.py       — запись готового пакета (scope drive.file)
├── gdrive_oauth.py       — OAuth-токен владельца (если нужно)
├── throttle.py           — лимиты запросов, очередь, ретраи
└── client.py             — единая обёртка над клиентом GDrive
```

## Кто сюда пишет

- Новая интеграция (например, Dropbox) → новый подкаталог `services/transport/<service>/`.

## Кто импортирует

- `services/sender.py` — отправляет пакет.
- `services/auto_runner.py` — инициирует отправку.
- `blocks/dashboard/` — ручная отправка из UI.
