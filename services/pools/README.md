# services/pools/ — справочники и пулы значений

Здесь живут все «словари», из которых система берёт подстановки:
организации, зарплаты, адреса, работодатели, вузы, профессии.

Это **данные + правила выбора**, без бизнес-логики документов.

## Принцип

- Один пул = один файл. JSON-данные лежат рядом или подключаются из `data/`.
- Правило выбора (по городу клиента, по отрасли, по должности) — внутри того же файла.
- При добавлении нового значения — пополняешь JSON и обновляешь индекс.
- Никаких SQL: пулы — это файлы, чтобы видеть глазами и рецензировать.

## Структура

```
services/pools/
├── organizations.py      — реквизиты работодателей (300+ записей)
├── salaries.py           — оклад по должности и отрасли
├── addresses.py          — пул российских адресов
├── employers.py          — зарубежные работодатели
├── universities.py       — вузы по профилю
├── professions.py        — профессии по отрасли
└── selector.py           — единая точка выбора пула по клиенту
```

## Кто сюда пишет

- Новый пул → новый файл. Регистрация в `selector.py`.
- Пополнение пула → правка JSON + индекс (через `scripts/audit/automap_pool.py`).

## Кто импортирует

- `services/values/personal.py`, `organization.py`, `finance.py` — читают пулы.
- `scripts/audit/` — аудит полноты пулов.
