# Состояние приёмки HTML-шаблонов

Дата: 06.10.2026

## Алгоритм (в сервисе)
- `scripts/qa_html.py --report` — вердикт по каждому документу: пустые переменные, наложения,
  выход за поле, прыгающие строки, мусор в тексте, расхождения с примером.
- `scripts/fix_overflow.py --apply` — автопочинка выхода за поле (перенос по ширине листа).
- `scripts/fix_broken_words.py` — склейка разорванных слов (наследие плохого текстового слоя PDF).
- `scripts/rebuild_contract.py` — пересборка договора по образцу (устраняет двойные слои блоков).

## Где сейчас
- Справки 3м/12м (4 шт.): выход за поле убран (50+ блоков). Единичные строки на границе поля.
- Письма (bridging, conversion), D12: годны или 1 замечание.
- Резюме: остались 2 замечания (наложение значения на заголовок, 2 строки-продолжения — ложные).
- E-02: 5 замечаний (наложения с подсказками бланка).
- Договор №18: пересобран по образцу — 3 страницы, 91 строка, двойные слои и повтор данных
  устранены. Осталась проблема: значения переменных длиннее строк образца -> при переносе
  блок налезает на следующий. Лечение: группировать строки образца в абзацы (один блок на абзац,
  ширина до правого поля, pre-wrap) — тогда переносы ложатся ровно.
- Remote Work №11: 11 замечаний — те же наложения после доклейки блоков, лечится тем же проходом.

## Правило
Пока документ не даёт вердикт «ГОДЕН» в `qa_html.py`, он не считается готовым.
