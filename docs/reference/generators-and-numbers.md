# Генераторы номеров в документах

Правила Андрея (16.10.2026). Номера никогда не берутся из подложки чужого образца:
у каждой переменной своя инструкция, по которой значение формируется.

## Ref. — ссылка справки

Формат: **одна заглавная латинская буква + 8 цифр + 3 заглавные латинские** — например `B19289961ADL`.

- если в настоящей справке клиента указана ссылка этого формата — берём её;
- иначе формируется генератором (детерминированно от ФИО, даты и соли).

Реализация: `services/values.py → gen_ref_no(client_name, doc_date, salt)`, паттерн `U + d*8 + UUU`.

## No — номер справки

Формат: **две строчные латинские буквы + 8 цифр** — например `ae32271197`.

Реализация: `services/values.py → gen_doc_no(...)`, паттерн `ll + d*8`.

## Номер карты (card_mask)

Формат маски: **БИН банка (6 цифр) + `******` + 4 цифры** = 16 знаков — например `551960******8340`.

Порядок:

1. если в настоящей справке банка карта указана — берём её значение как есть (её БИН и её цифры);
2. если карты нет (банк не выдавал или в документах её нет) — номер **формируется генератором**:
   БИН банка этого документа + `******` + четыре случайные цифры.

БИН по банкам (`services/values.py → BANK_BINS`):

- **TBANK**: 220070, 553691, 521324, 528041, 548387, 551960, 518901, 437773, 437783, 437772;
- **Сбербанк**: 220220, 427638, 427660, 427602, 427616, 427683, 427901, 546918, 676280, 639002.

Реализация: `mask_card(value, tpl_code, seed)`, `bank_bins(tpl_code)`, `read_client_card_mask(client_id)`.
Полный номер карты в документ не попадает никогда — только маска.

Инструкция переменной в базе (`template_variables.rule_text` для `card_mask`) приведена в соответствие
с этим правилом; метод переменной — `generated_or_client`.

## Сумма остатка прописью

Формат: `… balance is 469 143,71 rubles (four hundred sixty-nine thousand one hundred forty-three rubles 71 kopeks).`

- сумма цифрами — разряды через пробел, запятая перед копейками;
- пропись — **в скобках**, в конце предложения, со словами `rubles` и `kopeks`;
- единый источник формата: `services/values.py → _fmt_money`, `_balance_words_from` (дублирующие
  места записи удалены).

## Что проверять после правок шаблонов

1. Номера: `git grep`-подобная проверка по PDF на регулярки `[A-Z]\d{8}[A-Z]{3}` и `[a-z]{2}\d{8}`.
2. Карта: БИН в документе должен входить в список банка этого документа.
3. Сумма: пропись в скобках, одной строкой, порядок «сумма словами — rubles — копейки — kopeks».
4. Адрес: первая строка адреса начинается на одном левом уровне с именем клиента
   (в шаблоне это `left:296.88pt`, как у `{{ client_name }}`) — ведущих пробелов в значении быть не должно.
5. Форма: снимок «наш документ / образец заказчика» рядом (рендер первой страницы в PNG) и сверка глазами.
