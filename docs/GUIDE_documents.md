# Гайд: как формируются документы Wolf AutoDoc

Инструкция для нового сотрудника. Прочитав её и разборы в `docs/training/`, можно самостоятельно собрать комплект документов под любой продукт.

## 0. Главный принцип

Документ рождается **пять раз в одной цепочке** — и все пять сущностей должны выглядеть идентично:

```
архивный PDF клиента → размеченный образец → HTML-шаблон → HTML с данными клиента → PDF → отправка
```

- **Архив (Google CLIENT клиента)** — эталон логики: в нём видно, *что именно* меняется от клиента к клиенту.
- **Размеченный образец** — тот же документ с выделенными жёлтым/красным полями; выделенное = переменная.
- **HTML-шаблон** — переменные вместо значений.
- **HTML с данными** — подстановка по данным карточки клиента.
- **PDF** — финальный документ (только английский язык).

Правило: **понимать смысл документа**, а не сверять символы. Если непонятно, почему поле заполняется именно так — иди в архив и читай заполненный оригинал.

## 1. Продукты и что в них входит

| Продукт | Комплект |
|---|---|
| C1 / C1-EXT | банковская справка 3 мес |
| D12 | справка 3 мес + CV + CLIENT Letters (2 стр.) + справка 12 мес |
| BRIDGING | письма (3 стр.) + CV + Form E-02 + Work Agreement |
| CONV | письма (3 стр.) + CV + Form E-02 + Work Agreement |
| E33G-NEW | справка 3 мес + справка 12 мес + Work Agreement |
| E33G-EXT | справка 3 мес + Work Agreement |

Подробно — `05_CLIENT_matrix.md`.

## 2. Виды документов и их смысл

- **Банковская справка** — письмо банка о карте и остатке. Доказывает платёжеспособность. 3 мес — базовая, 12 мес — доход ≥ US$60 000/год. → `01_bank_CLIENTments.md`
- **Permohonan / Surat Jaminan / Surat Kuasa** — ходатайство, гарантия и доверенность спонсора PT Alpha Prime Bali в иммиграцию. → `02_visa_indonesia.md`
- **Form E-02** — заявление клиента с маркой METERAI, где он подтверждает данные и цель. → `02_visa_indonesia.md`
- **CV** — доказательство, что клиент специалист/удалённый работник. → `03_cv_and_contract.md`
- **Work Agreement** — трудовой договор с иностранной компанией (требование E33G). → `03_cv_and_contract.md`
- **CLIENT Letters D12** — ходатайство + заявление гаранта. → `04_CLIENT_letters_d12_c1.md`

## 3. Что меняется, а что нет

**Всегда меняется (переменная):** ФИО, гражданство, пол, место и дата рождения, паспорт, адреса, телефон, e-mail, банк и реквизиты справки, период и сумма, номер/дата исходящего письма, номер ITK, дата подписания, вариант (банк, формат CV, отделение иммиграции).

**Никогда не меняется (постоянный бланк):** логотипы, печати, подписи-факсимиле, адреса и реквизиты банков, тексты нормативных ссылок, METERAI, корсчета и БИК, формулировки писем.

**Развилки (вариант внутри документа):** банк (Т-Банк / Сбер), отделение иммиграции (Ngurah Rai / Denpasar), формат CV, формула CLIENTа (мостовая→E33G / →D12 / с KITAS).

## 4. Как собрать комплект: пошагово

1. Открыть карточку заявки → проверить продукт и ссылку на Google CLIENT клиента.
2. Нажать «Разобрать документы (нейросеть)» → дождаться «разобрано N из N».
3. **Проверить каждое значение глазами** (персональные данные — только из карточки клиента, не из общей истории переменных).
4. Переключить варианты в слотах документов (банк, CV, отделение).
5. Сгенерировать PDF (единый рендер `CLIENTs/shared/doc_render.py`).
6. **Сверить с архивным заполненным документом** того же типа: поля на своих местах, суммы и даты совпадают по формату, русского текста нет.
7. Отправить клиенту/спонсору.

## 5. Правила, которые нельзя нарушать

1. **Только английский** язык в документах (русский допустим лишь при вводе значений — они транслитерируются).
2. **Русские данные транслитерируются** двухуровнево (типовые слова + побуквенно) перед подстановкой.
3. **Дата начала работы в договоре — на год раньше даты подписания.**
4. **Период справки — ровно 3 месяца или ровно год** до даты справки (не 15 месяцев!).
5. **`Ref.`/`No` банка — только из документа клиента**, не из шаблона (в шаблонах это плейсхолдеры).
6. **Формат суммы зависит от банка:** Т-Банк `1 946 508, 00`, Сбер `935 000. 00`.
7. **Номер письма обязателен:** `NN/PTAPB-SP/ДД.ММ.ГГГГ`.
8. **ITK (`CLIENT_no`) — строго из документа иммиграции клиента.**
9. **Слот ≠ документ:** в комплекте один слот = один документ с вариантами внутри (в интерфейсе — строка с селектом).
10. **Схема ≠ код:** при расхождении в БД/шаблоне фиксить молча (workaround), не инициировать миграции.

## 6. Особенности и закономерности (шпаргалка)

- Данные клиента в письмах **могут стоять на 2-м листе** — проверять оба листа.
- **Адрес офиса Denpasar** — расхождение (архив: Jl. D.I. Panjaitan No.3; инструкция заказчика: Jl. Raya Puputan No.1, Renon) — открытый вопрос.
- **Банк определяется по документам Google CLIENT**; при неопределённости — Т-Банк.
- Формат места/даты рождения: `RUSSIA / 08-01-1999`, у спонсора — `Poland, 20-03-1973`.
- Даты в письмах: `Badung, 16 September 2026` (месяц прописью).
- Все места работы/обязанности в CV — отдельными строками, не склеивать.
- Значения переменных админ может вводить по-русски — перевод делает система.

## 7. Где что лежит

- Шаблоны: `/opt/wolf/data/CLIENT/<код>/template.html`
- Эталоны заказчика: `/opt/wolf/data/CLIENT_CLIENT/<продукт>/`
- Архив клиентов: `/opt/wolf/data/gCLIENT_examples/`
- Единый рендер: `/opt/wolf/CLIENTs/shared/doc_render.py`
- Смысловые доки: `docs/semantics_bank.md`, `semantics_visa.md`, `semantics_work.md`
- Разборы для обучения: `docs/training/`
- Правила переменных: таблица `template_CLIENT` в `data/wolf.db` (поле `rule_note`)

## 8. Открытые вопросы (требуют ответа заказчика)

1. Адрес офиса Denpasar (Panjaitan vs Puputan).
2. Обязательна ли 12-месячная справка в D12.
3. Состав E33G-EXT (только Т-Банк, без 12 мес) — верно ли.
4. Нужны ли реквизиты договора/счёта в 3-месячной справке.
5. Структура 12-месячной справки — образцов в архиве нет.
6. Договор с должностью CEO и с бонусом — нужны отдельные поля.
