## 2. Состав комплектов (порядок сборки)

**C1 / C1-EXT** (1 документ):
1. Банковская справка 3 мес — вариант **Т-Банк** или **Сбер**

**D12** (3–4 документа):
1. Банковская справка 3 мес (Т-Банк / Сбер)
2. CV — вариант **расширенный** / короткий / «Сиваев»
3. **CLIENT Letters** (Permohonan Visa D12 + Surat Pernyataan Penjamin, 2 стр. — один документ)
4. Банковская справка 12 мес (Т-Банк / Сбер) — в БД `required=0`

**BRIDGING** (4 документа):
1. Комплект писем, **3 страницы** (Permohonan + Jaminan + Surat Kuasa) — вариант **Ngurah Rai** или **Denpasar**
2. CV
3. **Form E-02** (bridging)
4. Work Agreement

**CONV** (4 документа):
1. Комплект писем, 3 страницы — вариант **Ngurah Rai** или **Denpasar**
2. CV
3. **Form E-02** (conversion)
4. Work Agreement

**E33G-NEW** (3 документа):
1. Банковская справка 3 мес
2. Банковская справка 12 мес
3. Work Agreement
*(CV не требуется)*

**E33G-EXT** (2 документа):
1. Банковская справка 3 мес (в БД только вариант Т-Банк)
2. Work Agreement

## 3. Варианты внутри слотов

| Слот | Варианты | Как выбирается |
|---|---|---|
| `bank_stmt_3m` / `bank_stmt_12m` | Т-Банк / Сбер | по банку клиента (определяется по документам с Google CLIENT) |
| `cv` | короткий / расширенный / «Сиваев» | по объёму опыта клиента; по умолчанию — расширенный |
| `bridging_letter` / `conversion_letter` | Ngurah Rai (Бартош) / Denpasar (Арине) | по отделению иммиграции, куда подаётся клиент |
| `d12_CLIENT_letters` | один документ (2 стр.) | — |

В карточке заявки каждая строка документа = **слот с переключателем варианта** (селект), а не отдельная строка. Это убрало путаницу вида «11 документов» в комплекте.

## 4. Цепочка CLIENTов статуса

```
C1 / C1-EXT (въезд, 60 дней)
        ↓ (за 3+ дня до окончания)
BRIDGING (мостовая, 60 дней) — комплект 4 документа
        ↓ (в течение 60 дней; для конверсии нужен запас ITK ≥ 31 дня)
CONV (Konversi Bridging → KITAS E33G) — комплект 4 документа
        ↓
E33G-NEW (первый KITAS, до 5 лет)
        ↓ (перед окончанием)
E33G-EXT (продление)
```

Альтернативная ветка: **Bridging → D12** (для инвесторов) — тогда комплект D12.

## 5. Пошаговый процесс изготовления

1. **Новая заявка** в карточке: клиент, продукт, дата, ссылка на папку Google CLIENT клиента.
2. **Разбор документов** (кнопка «Разобрать документы (нейросеть)») — фон скачивает файлы с CLIENT и раскладывает значения по переменным; на карточке индикатор «разобрано N из N».
3. **Проверка значений**: админ правит данные прямо в карточке (CLIENT-edit) — персональные данные берутся только из карточки клиента/заявки, не из общей истории переменных.
4. **Автоподготовка**: при создании заявки сразу формируются документы продукта (по набору слотов).
5. **Генерация PDF** — единый рендер (`CLIENTs/shared/doc_render.py`: шаблон + значения + транслитерация + суммы прописью + переносы строк).
6. **Проверка по образцу** — сверить с архивным заполненным документом клиента (архив = эталон логики).
7. **Отправка** — клиенту / спонсору (через бота менеджеру приходит PDF после ответа).

## 6. Какие данные нужны для всего комплекта

ФИО латиницей, пол, гражданство, место и дата рождения (формат `RUSSIA / ДД-ММ-ГГГГ`), паспорт (номер, выдан, срок), адрес в России (латиницей), адрес на Бали, телефон, e-mail, номер текущего разрешения (ITK), банк (Т-Банк/Сбер), реквизиты справки (карта, счёт, договор, баланс, период, Ref/No), должность и компания клиента, обязанности (для CV/договора), отделение иммиграции (Ngurah Rai/Denpasar), номер и дата исходящего письма.

## 7. На что обратить внимание

1. **E33G-EXT** содержит только вариант Т-Банк и не содержит справку 12 мес — проверить у заказчика.
2. **D12**: 12-месячная справка помечена как необязательная, хотя в эталонной папке заказчика их две.
3. **C1-EXT** — статус `researched`, состав не подтверждён.
4. **BRIDGING/CONV** не содержат банковских справок — сверить с актуальными требованиями иммиграции.
5. **E33G-NEW** (`implemented`) — самый проработанный продукт, остальные помечены как `ready`/`researched`.
