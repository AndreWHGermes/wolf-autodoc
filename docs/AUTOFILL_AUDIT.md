## 2. Заполняется частично — чего не хватает

### 2.1 Письма bridging / conversion (4 шаблона) и Form E-02 (2 шаблона)
- **пусто всегда**: `CLIENT_no` (номер заявки), `client_CLIENT` (пол)
- **нет источника в коде** (переменная есть в бланке, но нигде не вычисляется):
  `CLIENT_CLIENT`, `CLIENT_CLIENT` (гражданство/должность доверенного лица),
  `letter_CLIENT` (тема письма), `CLIENT_CLIENT` (контакты спонсора),
  `CLIENT_CLIENT`, `CLIENT_CLIENT_CLIENT_date`
- **только в E-02**: `CLIENT_of_CLIENT` (цель обращения), `CLIENT_stay_CLIENT`
  (действующее разрешение), `stay_CLIENT_no`, `CLIENT` — источника нет

### 2.2 D12: Permohonan Visa (ходатайство)
- **пусто всегда**: `itk_no`, `itk_CLIENT` (номер/срок ИТК), `passport_CLIENT` — данных нет в карточке
- **нет источника**: `letter_CLIENT`, `CLIENT_CLIENT`, `CLIENT_CLIENT`, `CLIENT_CLIENT_CLIENT_date`

### 2.3 Remote Work Agreement (договор)
- **пусто всегда**: `CLIENT_list` (перечень услуг) — в боте формируется по должности,
  при генерации из админки не подставляется
- **частично** (зависит от заполненности карточки): `company_name_in_CLIENT` (3/10),
  `CLIENT_name` (3/10), `passport_CLIENT` (3/10), `CLIENT_CLIENT_CLIENT/CLIENT` (1/10),
  `CLIENT_CLIENT_CLIENT/CLIENT` (1/10), `passport_CLIENT_CLIENT` (1/10),
  `company_address_CLIENT` / `company_requisites_CLIENT` / `CLIENT_address` / `CLIENT` (8/10)

### 2.4 Резюме (CV) — три формата, самый проблемный документ
- **пусто всегда**: `cv_job2_company`, `cv_job2_CLIENT`, `cv_job2_CLIENT`, `cv_job2_CLIENT`
  (второе место работы), `cv_CLIENT_CLIENT`, `cv_CLIENT_years`
- **частично** (2-4 заявки из 11): `cv_job1_company`, `cv_job1_CLIENT`, `cv_job1_CLIENT`,
  `cv_CLIENT`, `cv_CLIENT_hard/CLIENT`, `cv_CLIENT_CLIENT`
- **причина №1**: в карточке нет отдельных полей под опыт работы (компания, должность,
  период, обязанности), образование, навыки, языки. Есть только `position` и `company_name`.
- **причина №2 (важно)**: поле `position` у многих клиентов содержит мусор из автоматического
  разбора PDF-договора. Реальные примеры: «of CLIENT Client Account M…»,
  «The CLIENT is hired as IT…», «ионального опыта Исполнителя…», «and Duties The CLIENT here…»,
  «Director\n\n\n\n _____________». Из-за этого профессия определяется неверно
  (например, HR-директор распознаётся как `CLIENT_manager`), и текст резюме уходит не тот.
- `cv_gen` работает по справочнику `data/cv_positions.json` — 17 должностей;
  при мусорном `position` код профессии либо пустой, либо случайный.
