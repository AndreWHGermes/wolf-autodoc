## 2. Заполняется частично — чего не хватает

### 2.1 Письма bridging / conversion (4 шаблона) и Form E-02 (2 шаблона)
- **пусто всегда**: `application_no` (номер заявки), `client_gender` (пол)
- **нет источника в коде** (переменная есть в бланке, но нигде не вычисляется):
  `attorney_citizenship`, `attorney_occupation` (гражданство/должность доверенного лица),
  `letter_subject` (тема письма), `sponsor_contact` (контакты спонсора),
  `sponsor_nationality`, `sponsor_birth_place_date`
- **только в E-02**: `purpose_of_application` (цель обращения), `existing_stay_permit`
  (действующее разрешение), `stay_permit_no`, `occupation` — источника нет

### 2.2 D12: Permohonan Visa (ходатайство)
- **пусто всегда**: `itk_no`, `itk_expiry` (номер/срок ИТК), `passport_expiry` — данных нет в карточке
- **нет источника**: `letter_subject`, `sponsor_contact`, `sponsor_nationality`, `sponsor_birth_place_date`

### 2.3 Remote Work Agreement (договор)
- **пусто всегда**: `services_list` (перечень услуг) — в боте формируется по должности,
  при генерации из админки не подставляется
- **частично** (зависит от заполненности карточки): `company_name_in_quotes` (3/10),
  `employer_name` (3/10), `passport_number` (3/10), `annual_amount_numeric/words` (1/10),
  `monthly_amount_numeric/words` (1/10), `passport_issued_block` (1/10),
  `company_address_phrase` / `company_requisites_phrase` / `employee_address` / `nationality` (8/10)

### 2.4 Резюме (CV) — три формата, самый проблемный документ
- **пусто всегда**: `cv_job2_company`, `cv_job2_title`, `cv_job2_period`, `cv_job2_bullets`
  (второе место работы), `cv_education_school`, `cv_education_years`
- **частично** (2-4 заявки из 11): `cv_job1_company`, `cv_job1_title`, `cv_job1_bullets`,
  `cv_summary`, `cv_skills_hard/tools`, `cv_education_degree`
- **причина №1**: в карточке нет отдельных полей под опыт работы (компания, должность,
  период, обязанности), образование, навыки, языки. Есть только `position` и `company_name`.
- **причина №2 (важно)**: поле `position` у многих клиентов содержит мусор из автоматического
  разбора PDF-договора. Реальные примеры: «of Existing Client Account M…»,
  «The Employee is hired as IT…», «ионального опыта Исполнителя…», «and Duties The Employer here…»,
  «Director\n\n\n\n _____________». Из-за этого профессия определяется неверно
  (например, HR-директор распознаётся как `product_manager`), и текст резюме уходит не тот.
- `cv_gen` работает по справочнику `data/cv_positions.json` — 17 должностей;
  при мусорном `position` код профессии либо пустой, либо случайный.
