## Где живёт код

- **Движок + стили:** `/opt/wolf/blocks/shared/layout.py`
  - CSS-блок: `/* === Универсальный Zoom+Pan для HTML/документ-превью === */`
  - JS-блок: `/* === Универсальный Zoom + Pan для превью (любой контейнер с data-zoom-pan) === */`
  - JS-блок подсветки: `/* === Подсветка переменной: клик по полю/номеру ↔ подсветка в документе === */`
- **Подключение (разметка):** любой контейнер-обёртка с атрибутом `data-zoom-pan`,
  внутри — элемент-лист (`.html-stage` / `.doc-html-stage` / `iframe`).

## Утверждённое поведение (не менять)

1. **Тулбар НАД окном просмотра** (`.zp-shell` → `.zp-tools`): подсказка слева,
   кнопки справа. Внутри окна НИЧЕГО не накладывается на документ.
2. **Кнопки:** `−` / `%` / `+` / `⤢` (вписать) / `↺` (сброс позиции).
3. **Фон-подложка под листом:** серый `#E7EBEE` (лист белый, с границей и тенью).
4. **Нативная вертикальная полоса прокрутки** (`overflow-y:scroll`), стилизована.
5. **Высота окна** = высота листа, но не больше **78vh** (пустых полей нет).
6. **Вписывание по ширине** с зазором **18px** (`(cw-18)/natW`), максимум 100%.
7. **Навигация:** drag мышью / тач = прокрутка; обычное колесо = прокрутка;
   **Ctrl+колесо** = масштаб. Диапазон масштаба 20%–400%.
8. **Подсветка переменной:** клик по номеру/названию/полю переменной слева →
   мигание нужного места в документе + авто-центрирование; клик по `{{ var }}`
   в документе → подсветка и прокрутка к полю слева. Работает для всех документов.
9. **Drag-to-pan активен только когда документ больше окна** — иначе не мешает
   выделению текста («📌 Из выделенного → переменная»).

## Частые ошибки (не повторять)

- ❌ `transform: scale()`/`zoom` БЕЗ обёртки-канваса → layout-ширина не сжимается,
  содержимое вылезает за границу окна.
- ❌ Панель управления `position:absolute` ВНУТРИ окна прокрутки → кнопки «едут»
  вместе с документом и липнут к середине листа.
- ❌ Три рамки подряд (panel → wrap → stage) → у листа должно быть ОДНО обрамление.
- ❌ Регекспы вида `/["\\]/g` в JS внутри Python-строки ломают парсер
  (Invalid regular expression) и убивают весь `<script>`.
- ❌ Фиксированная высота окна (`64vh`) → пустые поля сверху/снизу.
