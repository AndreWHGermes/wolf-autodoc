# Миниатюры документов — отдельный блок (правило каркаса)

Зафиксировано 03.10.2026 по требованию Андрея. Относится и к прототипу, и к переселению на рабочий сайт.

## Где находится
Блок миниатюр — **отдельная зона слева** (вспомогательная), а не часть окна просмотра документа.
Внутри окна просмотра миниатюр страниц больше нет: там только сам документ и его шапка
(название, источник, «1 / 4» со стрелками, зум-панель).

## Ширина
Ширина блока миниатюр = ширине **развёрнутого меню** — 252 px (при окне ≤1360 px — 232 px,
при окне ≤1240 px зона скрывается целиком, чтобы центр остался широким).
Миниатюры заканчиваются ровно там, где заканчивается выехавшее меню.

## Функционал миниатюры
У каждой миниатюры свой квадратик-подтверждение справа:

**Вкладка «Сканы»** (файлы клиента, приходят с Google Диска):
- галочка стоит → «Скачано с Диска · дата»;
- идёт загрузка → янтарный квадратик с часами, полоса прогресса и «Качается с Диска · N%»;
- не подтверждено → пустой квадратик, подпись «не подтверждено»;
- файл не читается → подпись «не читается · загрузить заново», квадратик пустой.

**Вкладка «Наши»** (документы, которые создаёт система):
- галочка стоит → «Проверено»;
- снята → «не проверено»;
- черновик / не создан → подпись состояния («черновик · ждём скан», «не создан · из шаблона»).

Признак «это скан с Диска» берётся из вкладки (`data-pane="real"`), а не из текста подписи —
текст меняется при клике по галочке, поэтому по нему определять нельзя.

## Состав миниатюры
`[лист A4] Название / подпись состояния [квадратик-подтверждение]`, при загрузке — полоса прогресса
под названием. Выбранная миниатюра: светлая бирюзовая заливка, рамка и полоска слева.

## Клики
- клик по миниатюре — выбирает её и открывает документ в центре (заголовок карточки меняется,
  лист документа перерисовывается с анимацией);
- клик по квадратику — переключает подтверждение, документ при этом НЕ выбирается
  (`e.stopPropagation()`), подпись состояния обновляется тут же.
