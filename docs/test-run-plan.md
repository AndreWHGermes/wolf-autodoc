## Шаги прогона
1. **Новая заявка** для тестового клиента — через бота (@Wolf_AutoDoc_bot), как в жизни: клиент пишет, бот создаёт клиента + заявку (CLIENT `new`).
2. **Взять в работу** в админке → открыть карточку заявки.
3. **Сбор данных с Google CLIENT**: «Разобрать документы (нейросеть)» — подтянуть номера, остаток, карту, адрес из реальных файлов клиента.
4. **Документы**: проверить, что для заявки создан набор из набора продукта и PDF собрались автоматически.
5. **Заполненность**: у каждого документа должна быть зелёная метка «поля заполнены»; если красная — в ней перечень, чего не хватает.
6. **Проверка документа**: «Отметить Ок» — доступна только у заполненного документа.
7. **Отправка**: кнопка активна только когда все документы подтверждены и поля заполнены; иначе красная плашка с причиной.
8. **Заливка на Google CLIENT** — этот шаг сейчас заглушка (нужен доступ, см. ниже).
9. Повторить шаги 1–7 для продукта **C1-EXT**.

## Что нужно для заливки на Google CLIENT
Чтение файлов клиента уже работает (gdown по ссылке папки). Запись — не реализована.
Нужен один из вариантов доступа:
- **Сервисный аккаунт** (рекомендую): JSON-ключ из Google Cloud, в его адрес выдаётся доступ к тестовой папке на CLIENT.
- **OAuth клиента**: client_id/secret + токен пользователя.
Далее реализую загрузку (google-api-python-client) и в шаге 8 документы уходят в папку клиента.
