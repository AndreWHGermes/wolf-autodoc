# Каталог полей документов: смысл, источник, правило

Составлено по своду правил системы (/opt/wolf_v2/docs/VARIABLES_RULES.md) и шаблонам.

## bank_statement_3m__tbank — Банковская справка 3 мес. (Т-Банк)

- **address_live**
  - смысл/правило: Адрес: адрес проживания и регистрации — латиницей из карточки; в индонезийских письмах используется адрес пребывания в Индонезии.
  - источник данных: карточка клиента — из документа клиента: адрес проживания
  - как заполняется: Адрес фактического проживания из карточки клиента/анкеты. Для адреса в РФ в выписке используется формат: '<индекс>, <Obl/Krai/город>, G <город>, Ul <улица> , D. <дом>, Kv. <квартира>' — русские слова транслитерированы латиницей (Obl, G, Ul, D, Kv), без диакритики, регистр — первая буква заглавная. Д
- **address_live_2**
  - смысл/правило: (нет в своде — уточнить по коду и образцу)
- **balance_rub**
  - смысл/правило: Остаток и период справки банка — из справки клиента (или из карточки клиента).
  - источник данных: справка банка клиента — из документа клиента: справка банка
  - как заполняется: Сумма остатка на счёте (рублях). Порядок заполнения: 1) если в заявке или в документах клиента на Google Drive есть банковская справка/выписка — берём сумму остатка оттуда; 2) если данных нет — число генерируется в диапазоне своего типа справки: 3 месяца — от 190 000 ₽ (≈2 000 $) до 800 000 ₽, 12 ме
- **balance_words**
  - смысл/правило: Правило из базы: сумма остатка словами по-английски без названия валюты: «one million two hundred thirty-five thousand five hundred eight»
  - источник данных: карточка клиента

- **client_name**
  - смысл/правило: Имя в документе — транслитерация ФИО клиента (латиница), как в загранпаспорте. Одна и та же строка идёт во все документы пакета, поэтому берётся из карточки один раз.
  - источник данных: карточка клиента (латиница) — из документа клиента: загранпаспорт
  - как заполняется: ФИО клиента — всегда полностью: ФАМИЛИЯ ИМЯ ОТЧЕСТВО, латиницей и заглавными буквами (как в загранпаспорте). Отчество ставим всегда, даже если в оригинальном примере с Google Drive его нет. Откуда берём (по порядку): 1. карточка клиента — поля Фамилия, Имя, Отчество; 2. заявка клиента — строка «ФИО:
- **doc_date**
  - смысл/правило: Дата документа: день формирования; цифрами и в индонезийском формате — из одной даты.
  - источник данных: расчёт системы — из документа клиента: —
  - как заполняется: Дата формирования документа. Что это: Всегда текущая дата по календарю на момент сборки документа. Порядок заполнения: 1) дата подставляется автоматически при открытии страницы; 2) администратор может вписать другую дату руками — значение из ячейки принимается по Enter и сразу уходит в документ; 3) 
- **doc_no**
  - смысл/правило: Служебный номер документа (письма/заявки/справки) — уникальный номер в рамках заявки.
  - источник данных: расчёт системы — из документа клиента: —
  - как заполняется: Номер документа из строки «No » в справке банка. Формат в реальных справках: две строчные латинские буквы + восемь цифр (пример: ae32271197). Порядок заполнения: 1) если у клиента на Google Drive есть банковская справка — номер берётся оттуда; 2) если её нет — система генерирует номер от даты формир
- **period_from**
  - смысл/правило: Остаток и период справки банка — из справки клиента (или из карточки клиента).
  - источник данных: справка банка клиента — из документа клиента: справка банка
  - как заполняется: Начало периода выписки, ДД.ММ.ГГГГ. Для справки «3 мес.» период ровно 3 месяца (напр. 21.06.2026 → 21.09.2026), для «12 мес.» — 12 месяцев. Источник: строка баланса справки - **Повторяется в пакете:** `bank_statement_12m__sber`, `bank_statement_12m__tbank`, `bank_statement_3m__sber`, `bank_statement
- **period_to**
  - смысл/правило: Остаток и период справки банка — из справки клиента (или из карточки клиента).
  - источник данных: справка банка клиента — из документа клиента: справка банка
  - как заполняется: Начало периода выписки, ДД.ММ.ГГГГ. Для справки «3 мес.» период ровно 3 месяца (напр. 21.06.2026 → 21.09.2026), для «12 мес.» — 12 месяцев. Источник: строка баланса справки - **Повторяется в пакете:** `bank_statement_12m__sber`, `bank_statement_12m__tbank`, `bank_statement_3m__sber`, `bank_statement
- **ref_no**
  - смысл/правило: Служебный номер документа (письма/заявки/справки) — уникальный номер в рамках заявки.
  - источник данных: расчёт системы — из документа клиента: —
  - как заполняется: Номер документа из строки «No » в справке банка. Формат в реальных справках: две строчные латинские буквы + восемь цифр (пример: ae32271197). Порядок заполнения: 1) если у клиента на Google Drive есть банковская справка — номер берётся оттуда; 2) если её нет — система генерирует номер от даты формир
