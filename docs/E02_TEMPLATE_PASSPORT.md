- `word/header_26.png` — подложка из оригинала (300 dpi). В ней **остаются** точки полей,
  двоеточия, штриховая рамка METERAI, полосы, декларация. Стираются только значения

  Кегль 9.5 pt, Arial Bold, цвет `#0D1F59` (как в оригинале), фон текста — подложка.

## Подгонка длинных значений (services/doc_engine.py)
`fit_word_template()` — копия шаблона с кеглем под длину значения:
- ширина берётся из рамки абзаца `w:framePr/w:w`, запас по ширине 3 % (PIL-метрики vs LibreOffice);
- адрес (`address_in_indonesia`) — только ОДНА строка, кегль всегда 9.5 pt;
  предел длины = ширина эталонного значения из панели ('JL. DESA CEPAKA, CEPAKA, KEDIRI,
  TABANAN, BALI 80351' = 274.7 pt, ~52 знака). Длиннее — сокращаем текст
  (`services/address_fit.py`), а не переносим;
- рамка нижнего имени — 129 pt (до правого края поля 538.3 pt), поэтому длинное ФИО
  ужимается (проверено: 30 знаков → 7.0 pt, x1=533.4).
- Минимальный кегль — 5 pt.

## Один документ во всех трёх окнах
- Вкладка **Word** — `/templates/<id>/word_preview`, значения берутся из полей правой панели
  (в заявке — значения этого клиента), перезагрузка по вводу.
- **Просмотр PDF** — `/templates/<id>/preview_pdf` → `doc_engine.build_document(engine='word')`.
- **Сравнение** — `/templates/compare/<id>`, та же сборка «нашей» стороны.
Все три используют один шаблон и один движок, поэтому документ совпадает.
