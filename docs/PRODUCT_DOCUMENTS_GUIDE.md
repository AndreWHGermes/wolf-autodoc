# Какой продукт — какие документы подаются (инструкция)

Составлено 03.10.2026 по официальным источникам (imigrasi.go.id, evisa.imigrasi.go.id — FAQ «Document Requirement»)
и по эталонам заказчика (`data/product_templates/`). Источники указаны у каждого блока.

Обозначения: **МЫ** — документ печатает система; **КЛИЕНТ** — приносит клиент (кладёт в папку Google Drive);
**ИММИГРАЦИЯ** — официальный бланк/форма, которую заполняет заявитель.

---

## 1. C1 (B211A, виза кунджунган) — 60 дней, продление до 180

**Что подаётся**
| Документ | Кто | Примечание |
|---|---|---|
| Паспорт (скан страницы с данными, landscape, не обрезан) | КЛИЕНТ | срок ≥ 6 мес; для визы с продлением лучше 12+ |
| Фото цветное, однотонный фон | КЛИЕНТ | свежее (до 6 мес) |
| Билет обратный / подтверждение дальнейшего выезда | КЛИЕНТ | либо заявление о продлении/переходе |
| Подтверждение адреса проживания в Индонезии | КЛИЕНТ | отель/вилла, можно менять после въезда |
| Спонсор (гарант) — индонезийская компания | МЫ (PT ALPHA PRIME BALI) | без гаранта C1 не подаётся |
| Банковская справка за 3 месяца, минимум ~USD 2 000 | **МЫ** | у нас слот `bank_stmt_3m` (Т-Банк/Сбер) |

Источники: `evisa.imigrasi.go.id` FAQ (C1/B1), `indonesianvisas.com` (B211A 2026), `balibusinessvisa.com` (чек-лист 2026).
Продление C1-EXT: те же документы, дополнительно — фактическое место пребывания; паспорт физически сдаётся в иммиграцию на 7–10 дней.

## 2. D12 (Pra-Investasi) — многократная, 1–2 года, 180 дней на въезд

**Что подаётся**
| Документ | Кто | Примечание |
|---|---|---|
| Паспорт (скан данных + MRZ) | КЛИЕНТ | срок ≥ 6 мес; для многолетней — паспорт должен «перекрывать» срок визы |
| Фото цветное | КЛИЕНТ | однотонный фон |
| Банковская справка за 3 месяца, минимум ~USD 5 000 | **МЫ** | у нас `bank_stmt_3m` |
| Письмо-намерение об инвестиции (letter of intent) + рекомендательное письмо индонезийской компании | **МЫ** + спонсор | у нас «Sponsor Letters»: Permohonan Visa D12 + Surat Pernyataan Penjamin (2 стр.) |
| CV (резюме) | **МЫ** | у нас слот `cv`; подтверждается эталоном заказчика и списком документов иммиграции |
| Билет обратный / дальнейший | КЛИЕНТ | |

Источники: `royalvisa.id` (D12 checklist 2026), `emerhub.com` (D12 requirements), `evisa.imigrasi.go.id` FAQ (категория
«до 1 / до 2 лет»: паспорт, подтверждение проживания ≥ USD 2 000, фото, **CV**, travel itinerary).

## 3. E33G (Remote Worker KITAS) — новый

Официальный перечень (`imigrasi.go.id/wna/daftar-visa-indonesia/E33G`, `evisa.imigrasi.go.id` FAQ):
1. паспорт ≥ 6 мес — **КЛИЕНТ**
2. банковская справка за 3 месяца, минимум USD 2 000 — **МЫ** (слот `bank_stmt_3m`)
3. свежее цветное фото — **КЛИЕНТ**
4. **Curriculum Vitae (CV)** — **МЫ** ⚠ у нас в комплекте E33G-NEW CV НЕТ — расхождение, см. п. 7
5. travel itinerary (план поездки) — КЛИЕНТ
6. банковский счёт, подтверждающий доход ≥ **USD 60 000 в год** — КЛИЕНТ (выписка/письмо работодателя)
7. трудовой договор с компанией, зарегистрированной вне Индонезии — **МЫ** (у нас `remote_work_agreement`)
8. спонсор НЕ требуется; визу нужно использовать в течение 90 дней с даты выдачи

Дополнительно по практике агентств (`emerhub.com`): международная медицинская страховка (не туристическая).
В официальном перечне её нет — уточнить у заказчика.

## 4. E33G (продление)

Официально: «Izin Tinggal dari jenis visa ini dapat diperpanjang» — продление возможно онлайн через evisa.imigrasi.go.id
(`imigrasi.go.id/wna/daftar-visa-indonesia/E33G`). Документы продления официально не расписаны отдельным списком;
по практике используется тот же набор, что и при первичной подаче (паспорт, справка банка, CV, договор, фото).
У нас слоты: `bank_stmt_3m` + `cv` + `work_agreement`.

## 5. Bridging visa (Izin Tinggal Peralihan) — 60 дней

Официальная основа: Permenkumham No. 11/2024 (ст. 80 п. 3 f, 86A, 94A, 94B) — не отменена.
Условия: клиент уже в Индонезии, окно подачи — не раньше чем за 2 недели и не позже чем за 3 дня до окончания текущего разрешения.
**Обязателен спонсор (penjamin).**

**Что подаётся**
| Документ | Кто | Примечание |
|---|---|---|
| Surat Permohonan dan Pernyataan Jaminan (ходатайство + заявление-гарантия) | **МЫ** | официальный бланк есть на `imigrasi.go.id` (file/download); у нас 3-страничное письмо: Permohonan + Jaminan + Surat Kuasa |
| Statement Letter — **Form E-2 (E-02)** | **МЫ** | у нас `statement_letter_e02__bridging` |
| Текущее разрешение на пребывание (ITK / e-ITK / штамп о въезде) | КЛИЕНТ | без него bridging не подаётся |
| Паспорт (скан) + фото | КЛИЕНТ | |
| Договор удалённой работы | **МЫ** | у нас `remote_work_agreement` |
| CV | **МЫ** | у нас слот `cv` |

Источники: `flado.id/bridgingfaq`, `royalvisa.id/indonesia-bridging-visa-guide` (2026), письмо-образец с сайта иммиграции.

## 6. Конверсия / Alih Status (переход C1/B211A → KITAS E33G)

Состав тот же, что у bridging, но письмо и форма E-02 — «конверсионные» (у нас отдельные шаблоны):
письмо (Permohonan + Pernyataan + Surat Kuasa) — **МЫ**; Form E-02 (conversion) — **МЫ**;
CV — **МЫ**; договор удалённой работы — **МЫ**; паспорт, ITK, фото — **КЛИЕНТ**.
Условие: запас по текущему разрешению — не меньше 31 дня.

## 7. Расхождения: что готовим неверно (по состоянию на 03.10.2026)

1. **E33G-NEW: нет CV.** Официальный перечень документов E33G включает Curriculum Vitae. В нашем продукте
   `E33G-NEW` слот `cv` отсутствует → добавить (как в `E33G-EXT`, `BRIDGING`, `CONV`, `D12`).
2. **E33G-EXT: в матрице `docs/training/05_products_matrix.md` указано 2 документа (без CV)**, в базе — 3 (с CV).
   Официально CV в E33G есть → оставить CV, матрицу поправить.
3. **Дублирующий шаблон #8** (`d12_statement_letter__default`) — байт-в-байт совпадает с #7, ни в одном продукте
   не используется. Оставить как архив или удалить (решение владельца продукта).
4. **Банковские справки:** у `E33G-EXT` не было варианта Сбербанка — добавлено 03.10.2026.
5. **Фото клиента** используется только в `cv__format_detailed`; для E-02 в комплекте идёт полноразмерный бланк-скан.

## 8. Что должно проверять «готовность пакета» (предложение к разработке)

Сейчас блок «готовность» считает только наши документы (собраны/согласованы). Полнота пакета подачи шире:

- **Наши документы:** по каждому слоту продукта — статус `filled`/`verified`; ни одного `pending`/`error`.
- **Документы клиента:** на Google Drive в папке заявки должны быть найдены и распознаны:
  паспорт (страница с данными), фото клиента, банковская выписка (если справку делаем с неё),
  договор/контракт (если требуется), ITK / e-ITK — для bridging и конверсии, travel itinerary — для E33G/D12.
  Тип документа система уже определяет при разборе (`drive_scans.payload`: `doc_type` = passport / photo / bank_balance / …).
- **Значения:** ни одной незаполненной переменной в документах, которые собираются (кроме агентурных — их список уже есть в коде).
- **Итог:** зелёный статус только когда (1) все наши документы собраны, (2) все обязательные документы клиента найдены
  в папке Drive, (3) нет пустых полей. Иначе — красным с перечислением, чего именно не хватает.

Реализация: таблица «ожидаемые документы продукта» (наши слоты + клиентские типы) → сверка с `drive_scans` и
`application_documents` → вывод в карточке заявки. Перечень клиентских типов по продукту — из таблиц выше.
