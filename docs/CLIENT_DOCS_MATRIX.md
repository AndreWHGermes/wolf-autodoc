# Документы клиента по продуктам и переменные из них

**Минимум для любой заявки:** Загранпаспорт клиента, Фотография клиента, Адрес проживания (документ или карточка).
Справка банка обязательна: 12 месяцев — для нового E33G, 3 месяца — для C1, продления и D12.

Правило приоритета: **документ клиента сильнее карточки** — при расхождении берём значение из документа. Данные, которых нет нигде, поле остаётся пустым (не выдумываем).

## BRIDGING — CLIENT виза (60 дней на CLIENT)

**Обязательно от клиента:** Загранпаспорт клиента, Фотография клиента, Адрес проживания (документ или карточка).
**Стоп, если нет:** тип продукта, профессия клиента, паспорт клиента, фотография клиента, адрес пребывания в Индонезии, действующий KITAS/ITK.

- **Загранпаспорт клиента** (обязательно) — фото страницы с данными (может выглядеть по-разному — читаем значения)
  - `passport_CLIENT` → Bridging: письмо в иммиграцию (офис по адресу клиента), Remote Work Agreement (контракт)
  - `passport_CLIENT_date` → Remote Work Agreement (контракт)
  - `passport_CLIENT_by` → Remote Work Agreement (контракт)
  - `passport_no` → Bridging: письмо в иммиграцию (офис по адресу клиента)
  - `passport_CLIENT` → Employment Contract (договор работы с организацией), Remote Work Agreement (контракт), Statement Letter (Form E-02) — Bridging
  - `passport_CLIENT_CLIENT` → Remote Work Agreement (контракт)
- **Действующий KITAS / ITK** (по ситуации) — нужен для продления (E33G-EXT, C1-EXT) и конверсии (CONV)
  - `itk_CLIENT` → Bridging: письмо в иммиграцию (офис по адресу клиента)
  - `itk_no` → Bridging: письмо в иммиграцию (офис по адресу клиента)
  - `stay_CLIENT_no` → Statement Letter (Form E-02) — Bridging
